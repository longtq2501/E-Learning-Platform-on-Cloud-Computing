# Kịch bản trình bày demo (Defense Presentation Script)

Tài liệu này chuẩn bị các bước demo tuần tự cho buổi bảo vệ đồ án E-Learning Platform on Cloud Computing.

---

## 1. Khởi động hệ thống
- Chạy lệnh duy nhất tại thư mục gốc:
  ```bash
  docker compose -f infra/docker-compose.yml up -d
  ```
- Kiểm tra các container hoạt động:
  ```bash
  docker compose -f infra/docker-compose.yml ps
  ```
